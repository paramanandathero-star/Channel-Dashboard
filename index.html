Connect your data

Option 1: straight from YouTube (no script, no sheet). Create a free YouTube Data API key (Google Cloud Console → enable "YouTube Data API v3" → Credentials → API key) and restrict it to your website address and to that API only.

Option 2: from a published Google Sheet (only used if no API key above). File → Share → Publish to web → Entire document, paste the link, then give the gid number of each tab.
